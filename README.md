🧠 About Me

I am Adar Dey, an Information and Communication Technology (ICT) student at Comilla University with a strong passion for Mathematics, Physics, Programming, Artificial Intelligence, and Data Science.

My learning journey is centered around understanding fundamentals deeply, not simply collecting technologies.

I enjoy exploring two worlds in parallel:

🤖 AI / ML — learning Machine Learning deeply and preparing to move into Deep Learning, RAG, LLMs, and modern AI systems.

🧩 DSA — continuously strengthening Data Structures & Algorithms using C++, while studying algorithms and problem-solving techniques.

I also love writing and organizing what I learn. I have written learning material on Python and essential Python libraries for Data Science, while continuously creating handwritten notes on DSA topics such as Arrays, Binary Search, Graphs, and more.

My philosophy:
Learn the fundamentals → understand the mathematics → implement it → write about it → build with it.
